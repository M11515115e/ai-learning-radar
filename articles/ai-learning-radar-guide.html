AI 學習雷達使用指南

一句話摘要

以 local-first Markdown 保存 LINE 分享內容，並將明確公開的筆記產生成可搜尋的靜態網站。

重點整理

  • Markdown 是唯一主資料來源。
  • 原始內容與整理版分開保存。
  • 公開網站只收錄明確標記為 public 的筆記。
  • 私人資料與公開性不明內容一律保留在本機。

為什麼值得保存

這篇筆記說明知識雷達的操作方式、隱私邊界與長期維護原則。

可應用情境

  • 從 LINE 收藏文章、影片、工具與 GitHub 專案。
  • 建立每週學習摘要與趨勢觀察。
  • 從公開索引跨裝置搜尋已整理內容。

行動洞察

  • 分享連結時可附上「公開／私人」、「重要性」或預期用途。
  • 每週回顧並補上相關主題與延伸行動。
